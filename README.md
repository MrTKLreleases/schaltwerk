# Schaltwerk - releases

The packed builds of [Schaltwerk](https://github.com/mr-tkl), a learning game about digital
and analog circuits. The source code is private; this repository only holds the releases and
`latest.json`, which the game reads to update itself.

Download the newest release for your platform under *Releases*, unpack it and start
`Schaltwerk` (Windows: `Schaltwerk.exe`). From then on the game offers new versions itself.
